# Studio Bible

Every studio role reads this file before starting work. Edit it here, not inside episode files.

## Format
- Vertical 9:16, 30–45 seconds per episode
- Voiceover plus short on-screen text cards (max 8 words each)
- Cut-based editing by default

## Tone
- Warm, sincere, hopeful
- Motivation through small, real actions
- Never shaming, never preachy, never sarcastic toward the audience

## Characters
_To be filled in with the first episode. Each character: name, fruit, signature colour, one want, one fear._

## Palette
_Signature colours per character, plus a shared scene palette (3–5 colours). To be set with the Set Designer._

## Banned content
- Health, medical, or fitness outcome claims
- Money, investment, or income promises
- Guaranteed results of any kind
- Shame, fear, or guilt as motivation
- Unlicensed music or footage

## Closing line format
Every episode ends on a single hopeful line, held on screen for 2–3 seconds.
