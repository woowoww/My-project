# Studio Bible

Every studio role reads this file before starting work. Edit it here, not inside episode files.

## Format
- Vertical 9:16, 30–45 seconds per episode
- Voiceover plus short on-screen text cards (max 8 words each)
- Cut-based editing by default

## Tone
- Warm, sincere, hopeful
- Motivation through small, real actions
- Never shaming, never preachy, never sarcastic toward the audience

## Characters
### Pip the Pear
- **Fruit:** Pear (small, slightly lopsided, round-bellied)
- **Signature colour:** Soft sage green with a warm honey-gold blush
- **Want:** To finish one small thing she started, just once, all the way through
- **Fear:** That starting again means the first try was already a failure

_Added by studio-writer for pilot-01 ("starting over"). Set Designer to confirm the visual details._

## Palette
**Pip the Pear (signature):** soft sage green `#9CAF88` with honey-gold blush `#E0A526` on the cheeks only. Visual confirmed by Set Designer for pilot-01: sage body, small lopsided round-bellied shape. Honey-gold is reserved for Pip's blush so it always reads as her.

**Shared scene palette (4 colours, all episodes):**
- Warm cream paper `#F4EEDD`
- Worn oak `#A9774B`
- Late-light slate `#5C6B73`
- Ultramarine `#2F4FA3` (paint accent only)

Light: warm golden window light from camera-left, never a hard or dark look.

Pencil-line colour (not one of the four scene colours): graphite `#3A3F44`. Pencil lines only, never for props, light or Pip.

## Banned content
- Health, medical, or fitness outcome claims
- Money, investment, or income promises
- Guaranteed results of any kind
- Shame, fear, or guilt as motivation
- Unlicensed music or footage

## Closing line format
Every episode ends on a single hopeful line, held on screen for 2–3 seconds.
